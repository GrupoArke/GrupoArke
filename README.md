# Web de Grupo Arké

## Editar contenido

- Textos y enlaces: `index.html`.
- Colores y estilos generales: variables al comienzo de `styles.css`.
- Imágenes: carpeta `assets/images`.
- Comportamiento del menú y animaciones: `script.js`.

El HTML contiene comentarios `EDICIÓN RÁPIDA` y `REEMPLAZAR CONTACTOS` para encontrar los puntos más habituales de edición.

## Reemplazar una imagen

La forma más simple es conservar el nombre del archivo que se reemplaza:

| Uso | Archivo |
|---|---|
| Logo principal | `assets/images/logo-horizontal.png` |
| Portada | `assets/images/hero-stadium.webp` |
| Sección del desafío | `assets/images/challenge-athlete.jpg` |
| Modelo de trabajo | `assets/images/transition-collage.jpg` |
| Frase puente | `assets/images/closing-path.webp` |
| Retrato de Claudio | `assets/images/claudio-garcia.webp` |
| Retrato de Juan Marcos | `assets/images/juan-besagni.webp` |
| Testimonios | `luciana-aymar.webp`, `gabriel-batistuta.webp`, `paula-pareto.webp`, `walter-herrmann.webp` y `agustin-creevy.webp` |

Se recomienda usar JPG o WebP, con un ancho mínimo de 1600 px para las imágenes amplias y 800 px para los retratos.
